# 二级建造师学习助手

基于 Flutter 开发的二级建造师考试学习应用，面向备考复习场景，提供题库练习、错题管理、学习笔记、考试模拟和学习统计等能力。

## 项目简介

本项目致力于打造一款可离线使用的备考助手，帮助用户在手机端高效完成以下任务：

- 进行章节练习和模拟考试
- 管理错题与收藏题
- 记录学习笔记和学习计划
- 查看错题分析和学习统计
- 浏览教材大纲与章节知识内容

当前版本已经移除了旧版知识点语音播报入口，并不再依赖旧的 HTML 知识源文件，后续可以继续替换为更稳定的文本播报方案。

## 主要功能

### 1. 题库练习
- 支持单选题、多选题、判断题、填空题
- 支持按科目、章节、题型和难度筛选题目
- 支持查看题目解析与答案说明
- 支持答题进度展示与自动交卷

### 2. 模拟考试
- 提供考试模式，支持计时答题
- 结束后可查看答题结果与统计信息

### 3. 错题与收藏
- 记录错题和收藏题
- 支持错题分析，便于复习重点

### 4. 学习笔记
- 新建、编辑、删除笔记
- 支持标签分类与内容检索

### 5. 学习计划与统计
- 管理学习计划
- 查看章节完成情况与学习统计

## 技术栈

- Flutter
- Dart
- Provider
- SharedPreferences
- fl_chart
- flutter_tts

## 项目结构

```text
lib/
├── main.dart                  # 应用入口
├── data/                      # 静态题库与教材数据
├── models/                    # 数据模型
├── pages/                     # 页面组件
├── providers/                 # 全局状态管理
├── services/                  # 数据加载、存储与业务逻辑
├── utils/                     # 工具类
└── widgets/                   # 可复用组件（如有扩展）
```

## 数据来源

题库数据以 JSON 形式存放在以下目录：

```text
assets/questions/
├── law/
├── management/
└── practice/
```

## 运行方式

### 环境要求
- Flutter SDK 3.x
- Dart SDK 3.x

### 安装依赖

```bash
flutter pub get
```

### 启动应用

```bash
flutter run
```

### 构建 Android 安装包

```bash
flutter build apk --release
```

## 说明

- 当前版本以“高可用题库练习与学习管理”作为核心目标。
- 旧版知识点语音播放功能已经从主流程中移除，避免继续依赖低质量的语音播报逻辑。
- 旧的 HTML 知识源文件已经从仓库中移除，后续可由更规范的文本格式替换。
